レーシックやICLを調べていると「紹介クーポン」「紹介コード」という言葉をよく見かけます。ところが、実際に制度の案内を読むと、ウェブで番号を入力すると割引が付く「紹介コード」という仕組みは出てきません。

あるのは、券面に3つの項目を書いて受付へ出す、紙とデータの券です。ここを勘違いしたまま来院すると割引が付きません。制度の案内に沿って整理します。

そもそも誰が出している券か

この券は「ビューティークラブ」という会員制度の会員優待です。運営は株式会社ドクターピュアスキン、事務局は 0120-980-973（平日9:00〜18:00）。品川近視クリニックそのものが発行しているものではありません。

会員が知人や家族を紹介するときに使う券、という位置づけです。制度上の名称は紹介優待チケットといいます。

券面に3つ書いていないと無効

ビューティークラブの案内では、券面に次の3つを記入することになっています。

  1. 来院者名（施術を受ける人の名前）
  2. 管理番号（紹介する会員の会員番号）
  3. 紹介者名（紹介する会員の名前）

これを、施術料金の会計時までに受付へ提出します。会計が終わってからでは適用されません。

割引額はプランで変わる

両眼の施術を受けた場合の金額です。

（施術 / 割引額）

  • アマリスZレーシック … 5万円
  • クリスタルZレーシック … 3万円
  • スタンダードZレーシック … 1万円
  • 品川イントラレーシックアドバンス … 1万円
  • ICL（−4D未満） … 1万円
  • ICL（−4D以上） … 2万円

よく見かける「最大5万円割引」は、いちばん上のアマリスZレーシックの場合です。どのプランでも5万円になるわけではありません。

次の点もあわせて確認してください。

  • 片眼の場合は、施術料金も割引額もいずれも半額になります
  • この制度のサービス対象外となる施術があります
  • 福岡院の学割プランは割引額が異なります
  • 品川イントラレーシックアドバンスは、公式の料金表では東京院・梅田院・札幌院で実施とされています（名古屋院・福岡院では受けられません）
  • 割引の対象となる施術は、いずれも公的医療保険が適用されない自由診療です

使えないのはこういうとき

案内から読み取れる「適用されないケース」です。

  • 1人1枚。まとめて何枚も使うことはできません
  • 他の割引券との併用はできません。どちらを使うか選ぶことになります
  • 会計が終わったあとの提出は対象外です
  • 有効期限を過ぎてからの施術は対象外です
  • 過去に品川近視クリニックで施術を受けたことがある方は、紹介される側（割引を受ける側）になれません。再手術や追加の施術も対象外です

期限は「検査日」ではなく「施術日」で見る

券面には有効期限が印字されています。筆者が2026年9月5日に作成した券では「有効期限 2026年11月30日」でした。ビューティークラブのお知らせにある「キャンペーン第174弾」の期間と同じ日付です。

ここで間違えやすいのが、期限内に入っていなければならないのは「施術を受けた日」で、検査を受けた日ではないという点です。

適応検査から施術までは日が空きます。期限ぎりぎりに券を用意しても、施術が翌月になれば使えません。施術日の見通しが立ってから券を用意するほうが安全です。

期限が切れた券は使えませんが、案内によると、事務局に連絡すれば新しい券が発行されます。ただし次回の割引額・対象施術・有効期限は変更されることがあります。

フリマやSNSで出回っている券について

ビューティークラブの規約では、券の売買、ネットオークションへの出品、SNS・ブログ・街頭などで不特定多数に渡す行為が禁止されています。発覚した場合はサービス停止という扱いになると記載があります。

安く買えそうに見えても、券面の名前が違えば受付で止まりますし、規約違反の券です。
